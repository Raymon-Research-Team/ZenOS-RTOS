ZenOS RTOS for ARM Cortex-M and STM32

ZenOS is a compact real-time operating system designed for embedded applications running on ARM Cortex-M microcontrollers. The project is written in C++11/C and focuses on predictable scheduling, static task resources, lightweight inter-task communication, runtime diagnostics, and configurable safety mechanisms.

What is ZenOS RTOS?

ZenOS RTOS is an embedded operating system for developers building firmware on ARM Cortex-M devices such as STM32 microcontrollers. It provides the core services expected from a small RTOS while keeping the implementation close to the microcontroller and avoiding a general-purpose desktop-style runtime.

Scheduling and real-time behavior

The current kernel uses a 32-level ready bitmap with per-priority task queues and periodic release checks. Task creation uses static task resources, including task stacks, rather than a general-purpose heap. This architecture is intended for embedded systems where predictable resource use and explicit configuration are important.

Tasks, timing and IPC

ZenOS provides task management, timing services and common inter-process communication primitives. Applications can use events, mutexes, queues and semaphores to coordinate concurrent tasks. Periodic tasks are supported through the kernel's release mechanism.

Monitoring and safety mechanisms

The project includes configurable runtime diagnostics and safety-related mechanisms such as watchdog support, MPU integration where supported, CRC checks, RAM tests, task integrity checks, stack monitoring, CPU monitoring and deadline monitoring. These are configuration features, not a claim of functional-safety or medical-device certification.

Who is ZenOS for?

  • Embedded developers working with ARM Cortex-M microcontrollers.
  • STM32 firmware projects that need a small real-time kernel.
  • Engineers evaluating lightweight C++11 RTOS architectures.
  • Developers who need explicit task, IPC, timing and diagnostic facilities.
  • Researchers and students studying real-time scheduling and embedded operating systems.

Documentation and source code

Use the complete ZenOS guide for installation, API usage, task management, timing, IPC, configuration, monitoring and troubleshooting. The GitHub repository contains the kernel source, configuration and examples.
