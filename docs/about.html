⚡ Scheduling

The current kernel selects eligible work through a ready bitmap and per-priority queues, with periodic release checks and round-robin behavior where applicable.

🧠 Memory model

Task resources are statically allocated. There is no fixed ZOS_MAX_TASKS task-table constant; practical task count is constrained by available memory and implementation limits.

🛡️ Safety & monitoring

Watchdog, MPU, CRC, RAM test, integrity, stack and deadline mechanisms are configurable features, not a certification claim.

Engineering note: ZenOS is an RTOS project, not a certification package. System-level verification, validation and applicable regulatory requirements remain the responsibility of the product team.
