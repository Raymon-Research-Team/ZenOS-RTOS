ZenOS RTOS FAQ

Quick answers about the scheduler, task model, ARM Cortex-M support, IPC, memory behavior and configurable safety mechanisms.

01

What is ZenOS RTOS?

ZenOS is a compact C++11 real-time operating system for ARM Cortex-M embedded systems, including STM32-oriented projects. It provides scheduling, task management, timing, IPC and runtime diagnostics.

02

Does ZenOS use a fixed maximum task count?

The current design does not use a ZOS_MAX_TASKS fixed task-table constant. Tasks use statically allocated resources and the application determines how many tasks it creates, subject to available memory and implementation limits.

03

Which processors does ZenOS target?

ZenOS targets ARM Cortex-M microcontrollers and is designed for embedded firmware such as STM32 projects.

04

What scheduling model does ZenOS use?

The kernel uses a 32-level ready bitmap with per-priority task queues and periodic release checks.

05

What IPC features are available?

ZenOS includes events, mutexes, queues and semaphores for task synchronization and communication.

06

Does ZenOS support safety mechanisms?

Yes. Configurable mechanisms include watchdog support, MPU integration where supported, CRC checks, RAM tests, task integrity checks, stack monitoring and deadline monitoring.

07

Is ZenOS safety certified?

No. These mechanisms are configuration and engineering features; ZenOS itself is not claimed to be certified to IEC 62304, IEC 61508, ISO 26262 or DO-178C.

08
