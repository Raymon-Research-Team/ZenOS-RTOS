ZenOS RTOS FAQ

Current answers about the scheduler, task model, timing, ARM Cortex-M support, IPC, monitoring and configurable safety mechanisms.

01

What is ZenOS RTOS?

ZenOS 1.0.1 is a compact C++11 real-time operating system for ARM Cortex-M embedded systems, including STM32-oriented projects. It provides scheduling, task management, timing, IPC and runtime diagnostics.

02

Does ZenOS use a fixed maximum task count?

The current design does not define an OS_KERNEL_MAX_TASKS configuration constant or a fixed task table. Task resources are statically allocated, while the number of created tasks is constrained by the implementation, task-ID representation and available memory.

03

How are priorities configured?

The default configuration provides 32 priority slots and supports a configurable range of 2–256 slots. Priority 0 is reserved for the idle task; application priorities occupy the remaining configured range, with larger numeric values representing higher priority.

04

What scheduling model does ZenOS use?

The kernel uses a ready bitmap and per-priority task queues. It evaluates configured priorities and queue state when selecting eligible work; the implementation should not be interpreted as an O(1) scheduler independent of the configured priority range.

05

What timing defaults are used?

The default kernel tick period is 100 µs, configurable within the supported 100–1000 µs range. The default task stack size is 512 bytes; target and API constraints still apply to individual task definitions.

06

What IPC features are available?

ZenOS includes events, mutexes, bounded queues and semaphores for task synchronization and communication. Mutexes use IPC priority-ceiling behavior rather than priority inheritance.

07

Does ZenOS support safety mechanisms?

Yes. Configurable mechanisms include watchdog support, MPU integration where supported, CRC checks, bounded RAM integrity testing, task integrity checks, stack monitoring and deadline monitoring. These features are configuration and engineering mechanisms, not automatic certification.

08

Is ZenOS safety certified?

No. ZenOS itself is not claimed to be certified to IEC 62304, IEC 61508, ISO 26262 or DO-178C. Product teams remain responsible for system-level verification, validation, traceability and applicable regulatory requirements.

09
