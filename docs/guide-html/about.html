ZenOS RTOS

ZenOS is a compact C++11 real-time operating system for ARM Cortex-M. The current implementation focuses on predictable priority scheduling, static task resources, bounded IPC, timing and configurable diagnostics.

1–255

Usable priorities

Available when the scheduler is configured with 256 priority slots. Priority 0 is reserved for idle.

100 µs

Default tick

Configurable from 100 to 1000 µs, subject to the kernel validation rule.

4

IPC families

Events, mutexes, bounded queues and semaphores.

Scheduler architecture

The scheduler uses a ready bitmap and a queue for each configured priority. Priorities above 31 use derived extension storage. Periodic tasks carry a release interval and next-release timestamp, and the scheduler checks eligibility before selecting them.

Memory principle: expanding the priority range adds only the derived bitmap and queue-head storage required for the extra priority levels; there is no fixed 256-task table.

Tasks

Tasks have explicit priority, state, timing information and statically sized stacks. Custom stack sizes are supported.

IPC

Use events for signaling, mutexes for protected resources, queues for bounded data transfer and semaphores for resource counts.

Safety

Watchdogs, MPU, CRC, RAM testing, TCB integrity, stack protection and deadline monitoring are independently configurable.
