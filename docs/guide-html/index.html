ZenOS RTOS for ARM Cortex-M and STM32

ZenOS is a compact embedded real-time operating system for ARM Cortex-M microcontrollers, including STM32 projects. The kernel provides priority-based scheduling, task management, timing, events, mutexes, queues, semaphores, runtime monitoring and configurable safety mechanisms. Developers can use the documentation to learn how to build firmware with ZenOS, understand its scheduler and IPC model, configure the kernel, and troubleshoot embedded applications.

Start in seconds

From zero to a running task

ZenOS keeps the first step simple: initialize the kernel, create a task, then start the scheduler.

main.cpp3 steps
// 1. Initialize
os_init();

// 2. Create a task
os_task_create(task_led_toggle);

// 3. Start ZenOS
os_start();

Kernel at a glance

Capabilities reflected in the current source tree.

Priority-bitmap schedulingPriority-bitmap scheduler with per-priority task queues and configurable priority slots (default 16, range 2–256).
Static task resourcesTask stacks are allocated without a general-purpose heap.
IPC primitivesEvents, mutexes, queues, and semaphores.
Runtime diagnosticsStack, CPU, errors, watchdog, deadline, and integrity checks.
Safety note: ZenOS provides safety mechanisms and configurable target profiles; the project documentation does not claim that ZenOS itself is certified to IEC 62304, IEC 61508, ISO 26262, or DO-178C.
