Kernel at a glance

Key characteristics of the current implementation.

1..255 prioritiesUsable application range when configured for 256 slots.
100 µs default tickConfigurable kernel tick from 100 to 1000 µs.
Static task resourcesExplicit stacks and bounded kernel resources.
Four IPC familiesEvents, mutexes, queues and semaphores.
Important: ZenOS provides configurable engineering and safety mechanisms. It does not claim that the RTOS or a final product is certified to a safety standard.
