Support ZenOS RTOS

Help us keep ZenOS open, tested, documented, and moving forward. Your support helps fund embedded development, hardware testing, documentation, security work, and the infrastructure behind the project.

Every contribution is voluntary. ZenOS remains open source.

Why your support matters

ZenOS is being developed as a compact C++11 real-time operating system for ARM Cortex-M and STM32 microcontrollers. Building reliable embedded software takes more than writing code: it requires hardware, long-running tests, debugging, documentation, release infrastructure, and careful safety-oriented engineering.

If ZenOS is useful to you, supporting the project helps us spend more time on those parts of the work that make an open-source RTOS dependable for everyone.
