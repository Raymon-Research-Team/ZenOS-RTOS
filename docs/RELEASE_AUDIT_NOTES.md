# Release audit notes

The 1.0.1 release audit must verify every public claim against the implementation. In particular, the audit covers scheduler complexity, priority validation, stack allocation bounds, deadline action semantics, RAM-test naming, C/C++ header compatibility, optional-feature compilation, MPU alignment, CI coverage, documentation version strings, HTML claims, sitemap/robots placement, and release metadata.

This file is intentionally kept as an audit record rather than a claim of completion until the corresponding source checks have passed.
