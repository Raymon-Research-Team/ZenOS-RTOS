# ZenOS RTOS 1.0.1 Release Checklist

Release candidate branch: `release/1.0.1`

This branch is intended to make the implementation, configuration, documentation, site, CI, and release metadata consistent before publishing v1.0.1.

## Release rules

- Version: 1.0.1
- No certification claims are made by this release.
- Safety mechanisms are described as configurable unless explicitly enabled by the default configuration.
- Scheduler complexity claims must match the actual implementation.
- Hardware support claims must be limited to what is verified in the repository.
- Documentation and HTML must describe the current implementation, not historical behavior.
- Existing graphical documentation, Support, DonatR, and community content must be preserved.
